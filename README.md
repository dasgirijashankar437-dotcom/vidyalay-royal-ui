# Vidyalay — Royal UI Design Studio

**Powered by Novyra Vyren**

A premium royal navy-blue and gold landing page for the Vidyalay learning platform.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`. After the workflow runs successfully, open **Settings → Pages** in this repository and ensure **Build and deployment → Source** is set to **GitHub Actions**. The site URL should then appear on the Pages settings screen.

## Important limitations

- This is currently a **static UI preview**. The feature cards are design previews, not fully implemented learning tools.
- Sign-in and sign-up are intentionally shown as a future integration message on GitHub Pages. The Hatchable email-code authentication is not available on this static host.
- Do not enter or store real student personal information in this UI preview.
- The hero library image and web fonts are loaded from external providers and require an internet connection.
